# Ikoner

SVG-filerna här kommer från [Lucide](https://lucide.dev) och används
oförändrade, med `stroke="currentColor"` så de tar färg från CSS:en.

Lucide står under **ISC-licens** (© Lucide Contributors), som bygger
vidare på Feather Icons (MIT, © Cole Bemis). Båda tillåter fri
användning med bevarad upphovsrättsnotis — den här filen är notisen.

| Fil | Lucide-namn |
|---|---|
| `alarm-clock.svg` | alarm-clock |
| `calendar-days.svg` | calendar-days |
| `chart-spline.svg` | chart-spline |
| `message-circle.svg` | message-circle |
| `moon.svg` | moon |
| `pencil-sparkles.svg` | pencil-sparkles |
| `sport-shoe.svg` | sport-shoe |

`sport-shoe.svg` är dessutom källan till appens ikoner — `icon.svg`,
`favicon.svg` och de rastrerade filerna en nivå upp. Där ligger skon på
en volt-färgad bricka; här ligger den ren, som grannarna.
